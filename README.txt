PromptLens Android app (WebView)

APK banane ke 2 tareeqe:
1) Android Studio: File > Open > yeh folder > Build > Build APK(s)
2) Bina PC ke (GitHub): is folder ko ek naye GitHub repo mei upload karo (.github folder samet),
   Actions tab > "Build APK" run hone do (~3 min) > run kholo > Artifacts > PromptLens-APK download karo.

Icon: app/src/main/res/ (mipmap-* aur drawable-nodpi). Website: app/src/main/assets/index.html
